# Ming App Host Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking. 用户已授权在当前会话完成，不再等待第二次设计确认；本空目录不是 Git 仓库，不创建 worktree 或自动提交。

**Goal:** 真实 Kotlin/Wasm 应用通过 Ming SDK 读取授权文件，宿主拒绝未授权能力，并提供可重复测试。

**Architecture:** 父进程建立应用身份和只读资源表，子进程执行 Wasm，函数导入只允许 ming_v1。请求走匿名管道，宿主执行授权与资源回收，运行设置超时。

**Tech Stack:** Node.js 24 内置模块、node:test、Kotlin 2.3.20 wasmWasi、Gradle 8.14.5、JDK 21。

**Spec:** ../specs/2026-10-23-mingos-architecture-design.md

## Global Constraints

- Linux 为目标底座，本次跨平台开发原型不声称生产 Linux 隔离。
- 不接入完整 WASI；不允许普通应用导入宿主文件、网络和进程接口。
- 实际构建 Kotlin；纯手写 Wasm 夹具只用于攻击与故障测试。
- 先记录失败测试，再实现；文档不能把未执行检查写成通过。
- 不添加 npm 运行时依赖；锁定 Kotlin 和 Gradle。
