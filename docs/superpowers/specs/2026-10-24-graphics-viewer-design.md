# 批量文件、绘制协议与 Kotlin 图片查看器

日期：2026-10-24。用户已授权进入下一阶段，沿用 Rust/Wasmtime 宿主和 SDK-only 能力模型。

## 交付与边界

交付 SDK v2、真实 Kotlin 图片查看器、PNG 解码、有界绘制协议、CPU 参考渲染、原生窗口和输入回传。支持适应窗口、滚轮缩放、拖动平移、F/R 复位、1 原始比例、Esc 关闭。提供 headless 输出与脚本输入，用实际 Kotlin 产物验证交互，不以 Rust 硬编码界面替代应用。

CPU 参考后端用来验证协议、像素正确性和交互；GPU、Wayland 合成器、完整文本/无障碍、Linux 沙箱和无限期应用生命周期不在本阶段保证内。原生预览默认 60 秒；可信 CLI 可显式延长至最多 300 秒用于验收，普通 run 默认 5 秒、最多 60 秒。

## 版本与权限

保留 SDK 1 的 ABI/清单/256 KiB 文件上限。SDK 2 清单允许 ming_v1 与 ming_v2；SDK 1 导入 v2 必须拒绝。v2 允许显式授权的普通文件最大 8 MiB，没有新增路径、网络、设备接口。原生窗口和快照路径由可信 CLI 配置。

ming_v2 包含 file_read、image_open/width/height/close、frame_submit、event_next，以及受限的运行时 random_fill；全部使用 i32。涉及内存的接口只在 worker 验证导出的 memory 范围后复制，父进程不接收 guest 指针。批量文件每次最多 64 KiB，读取返回长度及内部 base64 payload，worker 复核长度再写入 guest memory。

## 图形与预算

图像资源引用已授权的文件句柄。仅 PNG；最大边长 4096，最多 4,194,304 像素，每图最多 16 MiB RGBA，总图像预算 32 MiB，最多 8 个图像句柄。解码器另设分配预算，拒绝尺寸炸弹、损坏和未知格式。

帧为小端 i32 头（magic、版本、宽、高、命令数、文本池字节数），后跟固定 8*i32 命令和 UTF-8 文本池。每帧最多 64 KiB、256 命令、4096 文本池字节；帧最多 4,194,304 像素且边长不超过 4096。支持矩形/圆角、图像、ASCII 参考文字、裁剪。所有长度、尺寸、资源句柄和坐标经验证；提交先完整解析验证再更新上一帧，失败不部分提交。

CPU 字体覆盖英文字母、数字和常用符号；完整 Unicode 字体栈属于后续工作。Kotlin 应用负责布局、缩放和平移状态，Rust 渲染器只执行已验证命令。图像解码一次，多帧复用资源；帧不会传输整张图像像素。

## 生命周期与输入

run 是无窗口模式，默认事件序列在初帧后返回关闭；--events 可加载可信脚本模拟缩放/拖动/尺寸事件。view 在主线程运行原生窗口，supervisor 在线程中运行，最新帧使用单槽覆盖避免队列积压，输入队列有界。

event_next 返回固定 16 字节（type,a,b,c）；原生模式最多等 20ms，空闲返回 idle，应用不为 idle 重画。关闭事件优先处理，关闭后的短宽限期若应用不退出则设置取消标志，watchdog 终止并回收 worker；不在窗口关闭后等待整段 60 秒。
