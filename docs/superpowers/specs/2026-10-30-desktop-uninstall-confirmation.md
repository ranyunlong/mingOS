# 桌面卸载确认

日期：2026-10-30。

## 目标

- Linux 桌面在配置了安装登记根时，为每个已登记应用提供 Dock `U` 卸载入口。
- 卸载操作必须经过已经呈现的当前桌面帧，并要求同一入口的按下和释放匹配；脚本、离屏会话和未呈现帧不能伪造用户确认。
- 普通卸载只撤销活动安装登记，明确显示私有数据会保留；公共目录和公共授权不由卸载流程删除或隐式撤销。
- 应用仍有运行代时不执行卸载，提示用户先关闭应用。
- 登记持久化失败时当前应用仍保持已安装，提示保留重试状态。

## 非目标

- 本阶段不删除私有数据。永久删除继续由独立的 `PurgePrivateData` 流程负责。
- 本阶段不实现安装包选择器、复制导入、更新迁移、多用户安装身份或 Windows 安装服务。
- 未配置安装登记根的开发兼容 catalog 不提供可执行卸载能力。

## 状态与交互

- Dock 每个应用的管理小入口分为 `U`（卸载）和 `S`（存储授权管理）；点击 `U` 后显示系统确认提示。
- 初始提示按钮为 `CANCEL` / `UNINSTALL`，正文明确 `PRIVATE DATA WILL BE KEPT`。
- 登记写入失败时按钮变为 `CANCEL` / `RETRY`，并显示 `UNINSTALL NOT SAVED`。
- 应用运行中时显示仅可关闭的 `CLOSE APP FIRST` 提示，不改变登记。
- 成功后从当前桌面 catalog 和待启动队列移除应用，私有目录保持可读写；重新安装仍可复用该目录。

## 验收

- CPU shell 和 GPU shell 均能稳定绘制卸载提示及 Dock `U` 入口。
- 未呈现、按下/释放位置不匹配、运行中和未配置安装根路径均 fail-closed。
- 真实 controller 路径完成卸载确认，登记变为 removed，私有数据仍保留；持久化失败可重试。
