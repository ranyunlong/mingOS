# ADR 0003：事件驱动的原生参考窗口

日期：2026-10-24。选择 winit 0.30.13 + softbuffer 0.4.8，保留已验证的 CPU 图形协议与 Kotlin 应用。

初始 minifb 试验已成功显示原生窗口并验证滚轮，但逐帧采样不能可靠保留同一帧内完成的按下/移动/释放。进一步补丁会把平台事件管理混入渲染与采样层，因此在当前阶段切换到事件驱动输入，不保留 minifb 依赖或 Windows 专用 IME FFI。

winit 负责原生事件和生命周期；softbuffer 负责安全持有的可写窗口缓冲。SDK、图像授权、Wasm 内存边界、绘制命令、预算和无窗口测试保持不变。输入事件逐条更新状态，高频位移在 bridge 中累积合并。

当前仍为 CPU 参考渲染，GPU/完整字体/无障碍与 Linux 实测留后续。窗口只读、不启用 IME 文本组合；未来文本组件需显式启用并接入系统输入法协议。
